## Key Decisions

1. **The referrer never leaves the browser** (§31): the client classifies search/social/direct/other from `document.referrer` and sends only the class — the raw URL (which can carry personal data) never crosses the wire. A stronger stance than ShareEvent's server-side optional attribution.
2. **The surface + market are derived server-side** (§16): the landing beacon sends only the path; `resolveFromPath` + the segment grammar classify the surface — the beacon cannot claim a surface the URL does not carry. Unknown-but-parseable paths land honestly as APP.
3. **Vendor-neutral SEO observations** (§17's rule applied to SEO data): the store speaks page × query × day with impressions/clicks/position; any feed that speaks the shape imports. The pagePath census guard means observations only ever land for pages the platform declares indexable. P9-S4 wires the country-specific operations.
4. **Machine re-runs never log** (the logQuery contract): a census must not fabricate reader intent — the §32 families count reader actions, and the analytics module's own engine re-runs are not reader actions.
5. **The TRUE first revision, unfiltered** (§36): time-to-publish windows on the real first publish, never on an in-window correction; the never-a-silent-edit check (correction-driven revisions) covers the correction side separately.
6. **The §25 weighting is a sort, not a rewrite** (§25): the reason-seeded priority still leads (it is the field editors see); traffic orders within a status bucket — "prioritised by content traffic/importance" as a tiebreak-first-class signal, every number §9-derived on the row.
